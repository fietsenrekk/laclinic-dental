# LACLINIC DENTAL — static site

Rebuild of [laclinicdental.com](https://www.laclinicdental.com/) from Webflow into a static,
bilingual (NL-BE / EN) site. No CMS, no backend, no cookies, no third-party scripts.
**64 routes generated from JSON by a zero-dependency Node script.**

> **Read [`CLIENT_ACTIONS.md`](CLIENT_ACTIONS.md) first.** Two items are blocking — whether the
> practice opens on Saturday, and which booking route is canonical.

## Build

```bash
node tools/fetch-assets.mjs   # pull source frames from the Webflow CDN (once)
node tools/images.mjs         # colour grade + grain + AVIF/WebP ladder (needs ffmpeg)
node tools/build.mjs          # generate dist/
node tools/audit.mjs          # structural audit — fails on dead links, clipart, hreflang gaps
```

For a GitHub Pages project site:

```bash
BASE_PATH=/laclinic SITE_ORIGIN=https://owner.github.io node tools/build.mjs
```

## Local preview

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File ../serve-laclinic.ps1
```

Serves `dist/` on <http://localhost:4214>.

## Verification

```bash
node tools/verify-trace.mjs   # traced logo vs source bitmap, pixel diff
node tools/check-skin.mjs     # skin tone + teeth across all six portraits
node tools/audit.mjs          # 64 routes: links, meta, headings, nav/footer parity, JSON-LD
node tools/checks.mjs         # headless Chrome: console, CLS, reduced motion, no-JS, keyboard
node tools/shot.mjs / 390 1440 2560   # screenshots, flags horizontal overflow
```

`tools/checks.mjs` and `tools/shot.mjs` need the dev server running. Point them elsewhere with
`CHECK_ORIGIN` / `SHOT_ORIGIN` to run against the live URL.

## Design in one paragraph

The wordmark is eight letters of eight different heights on one shared baseline
(`82 · 75 · 74 · 82 · 92 · 100 · 92 · 74`). That is an occlusal profile — a row of teeth. Those
eight ratios drive the section rhythm of every page, which makes a uniform grid structurally
impossible. The palette is the sampled black-and-white system with no accent, because the clinic
has never had one. There are no icons at all; the twelve stock PNGs on the live site were replaced
with a numbered typographic index. Type is one variable family. The signature moment is the
wordmark assembling itself as a bite closing, in 0 KB.

## Changing the two decisions

**Saturday** — `data/site.json` → `hours.days` → the Zaterdag entry. Rebuild. The footer, the
practical page, the FAQ and the `openingHoursSpecification` structured data all follow.

**Booking** — `data/site.json` → `booking`. Every CTA on the site is one component
(`bookingCta()` in `tools/build.mjs`) reading from it. `tools/audit.mjs` fails the build if any
page links straight to the scheduler instead.

## Stack

Nothing. HTML, CSS, and 5.5 KB of JavaScript using the Web Animations API and one
IntersectionObserver. Fonts self-hosted (Archivo Variable, OFL). ffmpeg for images. Node ≥ 20 for
the build.
